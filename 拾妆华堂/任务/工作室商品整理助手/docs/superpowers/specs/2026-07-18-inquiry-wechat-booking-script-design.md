# 拾妆华堂询价转微信与预约话术设计稿

日期：2026-07-18  
状态：用户要求直接实施

## 一、目标

当客户在小红书、闲鱼或其他平台询价后，通过一套自然、明确的消息流程完成：

1. 发送公开价目表；
2. 引导添加拾妆华堂工作室微信；
3. 收集日期和服务需求；
4. 确认订单金额；
5. 收取订单总金额的 10% 作为预约金；
6. 预约金到账后锁定服务日期。

## 二、固定信息

- 工作室微信号：`shizhuanghuatang`
- 添加方式：微信二维码＋微信号同时发送
- 添加微信备注：`姓名＋咨询项目`
- 预约金：订单总金额的 10%
- 预约金用途：抵扣订单尾款
- 锁定档期条件：需求、价格和时间确认，并收到 10% 预约金
- 暂不在话术中承诺取消、退款和改期规则；相关规则另行制定后补充

## 三、消息结构

### 1. 平台首次询价回复

目的：不只发一张价目表，而是告诉客户下一步如何获得档期确认。

内容必须包含：

- 简短欢迎；
- 提示客户查看价目表；
- 说明不同日期、到店/上门和复杂需求需要确认；
- 引导添加工作室微信；
- 提供微信号和二维码；
- 要求备注姓名与咨询项目。

### 2. 添加微信后的欢迎与需求收集

一次收集五项信息：

1. 姓名或称呼；
2. 服务日期和最晚完成时间；
3. 咨询项目；
4. 到店或上门，上门需提供区域；
5. 人数、服装和喜欢的参考图。

### 3. 方案和价格确认

用结构化格式确认：

- 服务项目；
- 日期和时间；
- 到店或上门地点；
- 人数与包含内容；
- 商品价格；
- 上门交通费或其他提前确认费用；
- 订单总金额。

### 4. 收取预约金并锁定日期

预约金计算规则：

`预约金 = 订单总金额 × 10%`

消息中明确：

- 预约金可抵扣尾款；
- 档期在收到预约金后正式锁定；
- 付款后请发送付款截图或告知已支付；
- 收到后工作室回发预约确认信息。

### 5. 预约成功确认

确认信息必须包含：

- 客户称呼；
- 已预约项目；
- 日期和完成时间；
- 到店地址或上门地点；
- 订单总金额；
- 已收预约金；
- 待付尾款；
- 下一步：服务前准备事项将在预约日前发送。

### 6. 未添加微信提醒

客户收到价目表后 24 小时仍未添加微信，只提醒一次。语气温和，不制造虚假紧迫感；询问是否需要继续确认档期，并再次提供微信号。

### 7. 已添加但未支付预约金

只说明当前日期尚未锁定，并询问是否继续保留预约流程；不使用“最后一个名额”等未经证实的催单表达。

### 8. 个人微信引导至工作室微信

覆盖以下两种场景：

- 个人微信一对一聊天：说明后续报价、档期、预约和订单统一由工作室微信管理，并同时发送二维码与微信号。
- 个人朋友圈通知：告知妆造、写真与新娘业务迁移到工作室微信，方便客户保存和转发。

如果客户仍在个人微信继续沟通，先正常回应，再温和说明为避免日期或需求遗漏，需要转到工作室微信完成订单确认。

## 四、语气规范

- 亲切但不过度使用“亲”“宝宝”“小姐姐”等称呼；默认使用“你好呀”或客户姓名。
- 说明加微信的理由是“确认档期、方案和预约”，不是单纯导流。
- 不承诺未确认的妆造效果、场地、交通费或特殊服务。
- 不用压迫式催单，不虚构档期紧张。
- 价格以《拾妆华堂公开价目表 V2》为准，定制项目先了解需求再报价。
